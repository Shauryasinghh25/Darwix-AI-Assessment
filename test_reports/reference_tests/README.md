# Evidence

Use this folder for artifacts that demonstrate the system working:

- transcripts
- screenshots
- latency tables
- recordings
- source samples
- retrieval test outputs

Keep test_reports grouped by question, for example:

- `test_reports/voice_assistant/`
- `test_reports/knowledge_system/`
- `test_reports/regional_bots/`
- `test_reports/realtime_analytics/`
